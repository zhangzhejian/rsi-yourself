# 本地问卷库

本库保存可复用的通用问卷定义，不保存个人回答。当前 8 个模块来自现有入组表单，均为待核验版本，不代表已完成中文版验证或获得再分发许可。

| ID | 内容 | 按需取用场景 |
|---|---|---|
| profile | 基本信息与固定安排 | 入组、安排变化 |
| health-screen | PAR-Q+ 改编与补充健康问题 | 运动前了解情况；不是完整官方筛查 |
| body-measures | 体重、腰围、血压与测量日期 | 建立身体指标基线 |
| isi | 7 题失眠严重程度 | 最近两周的睡眠主观体验 |
| pss10 | 10 题知觉压力 | 最近一个月的压力体验 |
| phq2 | 2 题情绪筛查 | 可选，最近两周 |
| gad2 | 2 题焦虑筛查 | 可选，最近两周 |
| goals-boundaries | 目标、约束、偏好、隐私边界 | 确定周期目标或目标变化 |

## 取用

在仓库根目录执行，无需安装依赖：

```sh
python3 tools/questionnaires/library.py list
python3 tools/questionnaires/library.py show pss10@1.0.0
python3 tools/questionnaires/library.py compose isi@1.0.0 pss10@1.0.0
python3 tools/questionnaires/library.py validate
```

`show` 输出单个完整定义；`compose` 按指定顺序输出组合 JSON，保留各模块的来源、限制和版本。命令只读库文件，不启动采集，不写入回答，不联网。

## 数据约定

每个 JSON 保存稳定 ID、版本、语言、来源、核验状态、限制、计分规则和表单字段。`form` 兼容现有表单字段形态；其中 `score` 是旧渲染器标识，`scoring` 才是本库的计分约定。新调用方不得据旧标识套用旧页面的分档。

量表选项以 0 为起点计分；PSS-10 的反向题下标为 3、4、6、7（即第 4、5、7、8 题）。缺答不计总分。本库只定义总分，不自动诊断或给出严重程度分档。PSS 开发团队明确没有官方低中高分界值。

现有 `tools/intake/index.html` 尚未改为从本库加载，仍保留原有显示逻辑。本库是可复用定义的维护入口；未来迁移页面时必须显式记录版本，不能静默替换旧答案对应的题目。

## 维护规则

1. 新增模块前记录原始来源、测量对象、回忆时段、适用人群、中文版本及使用条件。无法确认的项目标记待核验，不以论文引用替代译本验证。
2. 已用于收集回答的版本不覆盖。题目、选项、顺序、计分、回忆时段变化时新增版本文件。CLI 取用必须指定完整版本，不默认选择最新版。
3. 中文与授权核验未完成的量表只作为项目已有定义留档；对外分发或正式标准化使用前完成核验。本库存在不代表允许再分发量表。
4. 个人回答放在 `instances/<name>/private/questionnaires/`，记录 `instrument_id`、`instrument_version`、`answered_at` 和原始回答。组合问卷按模块分别关联版本；不在本库保存姓名、答案、预填值或报告。
5. `/instances/` 已由仓库 `.gitignore` 忽略；禁止强制加入 Git。通用定义与工具可纳入版本管理；个人回答和预填数据不得提交或上传。
