# 数据采集：人的 RSI 从哪里获得记录

整理日期：2026-10-30。本文是通用方法，不绑定具体设备和软件。
每个人按自己的条件选择数据源，写在个人配置里；示例见 `instances/zzj/data-sources.md`。

## 1. 为什么要先解决数据

RSI 五块中，"02 怎么改"要从记录里找问题，"03 怎么判断变好"要对照记录做判断。没有记录，循环就跑不起来。

人不可能每天把所有事情写下来；靠事后回忆和自评，偏差也很大。
所以基本思路是：**工具自动采集为主，人只补工具采不到的部分。**

## 2. 按"要回答的问题"给数据分类

先分类再选工具。同一类问题可以由不同工具回答，换工具不影响方法。

| 类别 | 回答什么问题 | 常见来源 | 能否自动采集 |
|------|-------------|---------|-------------|
| 时间与行为 | 时间花在哪，做了什么 | 日历、屏幕使用时间、应用和网页记录、工作软件历史（代码提交、文档编辑、AI 对话） | 能 |
| 身体状态 | 睡眠、恢复、活动量 | 智能手表或手环、体重秤、手机计步 | 能 |
| 交流与环境 | 和谁交流、交流了什么、会议占多少时间 | 录音转写、会议纪要、消息记录 | 能 |
| 产出与结果 | 做成了什么 | 任务完成情况、交付物、业务指标、交易结果、考试成绩 | 大部分能 |
| 主观状态 | 精力、情绪、满意度 | 定时打分、随机时刻提问 | 只能由本人提供 |
| 执行记录 | 实验计划有没有执行 | 优先从前四类自动推断；推断不了再打卡 | 部分能 |

## 3. 采集方式分四级

从上往下优先。能用上一级解决的，不用下一级。

| 级别 | 方式 | 人的成本 | 例子 |
|------|------|---------|------|
| L1 被动自动 | 设备和软件自动产生、自动导出 | 一次性设置 | 手表记录睡眠、日历、屏幕使用时间 |
| L2 AI 起草，人确认 | AI 汇总 L1 数据写成草稿，人只改错 | 每天约 1 分钟 | 每晚的日报草稿 |
| L3 轻量主动 | 打分、打卡、一句话 | 每次几秒 | 精力 1–5 分；实验打卡 |
| L4 主动书写 | 写日志、写复盘 | 每次几分钟以上 | 只用于每周复盘 |

设计实验时，优先选择能被 L1 测量的指标。
例如实验是"11 点前睡觉"，入睡时间交给手表记录，执行情况也能自动判断，不需要本人汇报。

## 4. 选择数据源的五个标准

1. **相关**：能回答当前目标或当前实验的问题。说不出回答哪个问题的数据源，不接入。
2. **自动**：不依赖本人每天记得去做。
3. **准确**：误差要小于想测量的变化。已知误差要写下来，例如录音转写错字多。
4. **可持续**：设备愿意一直戴，软件一直开着，维护成本低。
5. **隐私可控**：可以本地保存；涉及他人的内容有事先写好的处理规则。

## 5. 通用数据流程

```
采集 → 原始层 → 标准化层 → 摘要层 → 确认层 → 进入改进循环
```

| 层 | 做什么 | 规则 |
|----|-------|------|
| 原始层 | 保存各来源的原始数据 | 只读，不修改、不删除 |
| 标准化层 | 统一成相同格式：时间、来源、类别、数值或文本 | 由脚本完成，可重复执行 |
| 摘要层 | AI 按天、按周汇总 | 摘要可能出错，不能替代原始数据 |
| 确认层 | 本人改错、补充主观打分 | 只改摘要，不改原始数据 |

原始层对应 RSI 的"评价标准不可修改"：判断实验效果时，必须能回到原始数据。

## 6. 分阶段接入

1. **基线期（2–4 周）**：只接 L1 自动来源，加每天一次 L3 打分。期间不做任何改变，目的是了解平时的波动范围。
2. **实验期**：按实验需要增加数据源；每个实验只加一项执行记录。
3. **不先全量囤数据**：数据源越多，维护成本和隐私风险越高，噪声也越多。

## 7. 不同条件下的配置

| 配置 | 数据源 | 适合谁 |
|------|-------|-------|
| 最低 | 手机日历 + 手机屏幕使用时间 + 每天一次打分 | 没有可穿戴设备，不想装软件 |
| 常规 | 最低配置 + 智能手表 + 工作软件历史 | 大多数知识工作者 |
| 完整 | 常规配置 + 电脑使用记录 + 录音转写 + 业务结果数据 | 愿意投入搭建，并且隐私规则明确 |

## 8. 隐私规则

- 原始数据默认只存在本地；推送到手机或分享给别人时只用摘要。
- 原始数据不进版本库。
- 涉及他人的数据（录音、消息），事先写明保留什么、丢弃什么。
- 录音涉及他人时，了解并遵守所在地关于录音和知情同意的规定。

## 9. 个人配置怎么写

每个人一份数据源配置，逐项写明：

| 字段 | 说明 |
|------|------|
| 数据源 | 设备或软件名称 |
| 类别 | 第 2 节的六类之一 |
| 级别 | 第 3 节的 L1–L4 |
| 获取方式 | 文件位置、导出方式或接口 |
| 频率 | 实时、每天、每周 |
| 状态 | 已在产生 / 需要设置 / 未确认 |
| 已知问题 | 误差、缺失、维护成本 |
| 隐私处理 | 保留什么、丢弃什么 |
